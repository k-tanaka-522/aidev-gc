# 共同利用ガバメントクラウド Hello World アーキ比較検証 — 標準WBS

## 1. WBS概要

本WBSは、`gc-standard-wbs`（9フェーズ標準WBS）を本サンプル案件向けにテーラリングしたもの。**「共通部1系統＋バッチ/非同期3パターン（A: Lambda / B: AWS Batch / C: SQS+ECS Fargate）」を並行設計・構築・見積比較する**構造を採用する。

### 1.1 適用係数（PROF-001 / TAIL-001 より）

| ルール | 適用値 | 根拠 |
|--------|--------|------|
| 移行方式係数 | 2.5（新規構築） | ただしアプリはHello Worldスケルトンのため、Phase 2業務要件は×0.6補正 |
| 自治体規模係数 | 1.6 | 省庁級（共同利用・複数テナント） |
| ネットワーク複雑度係数 | 1.4 | 複雑（LGWAN＋テナント分離） |
| セキュリティレベル係数 | 1.5 | 高（ISMAP対応） |
| GC利用方式係数 | 1.2 | 共同利用（ガバナンス・GCAS-SSO追加） |
| ASP連携係数 | 1.0 | ASP 0個 |

### 1.2 比較見積の構造ルール

```
総工数 = [共通部] + [パターンA固有] + [パターンB固有] + [パターンC固有]
```

- 共通部（オンラインFargate public/private、VPC、セキュリティ、GCAS環境、監視、CDK共通スタック）は **1回のみ計上**
- バッチ・非同期の設計/構築/見積は **パターンごとに独立計上**（差分の見える化）
- Phase 4-5は「共通部を先行確定 → パターン固有を並行」する

### 1.3 スコープ方針

- **主スコープ: Phase 0〜5 ＋ アーキ比較見積（Phase 3）**
- Phase 6（テスト）は疎通・動作確認の簡易レベル
- Phase 7（移行）・Phase 8（運用）は **本案件スコープ外**（新規構築・検証目的のため）
