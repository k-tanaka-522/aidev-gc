# さくら市GC移行案件 — 標準WBS（全フェーズ）

## 1. WBS概要

本WBSは、さくら市GC移行案件の全フェーズ（Phase 0～8）における**標準的なタスク分解と工数目安**を記載したドキュメント。

### 1.1 適用ルール

| ルール | 適用値 | 根拠 |
|--------|--------|------|
| 移行方式係数 | 1.3 | R1（既存ロジック活用+アーキテクチャ調整） |
| 自治体規模係数 | 1.0 | 中規模（人口12万） |
| ネットワーク複雑度係数 | 1.0 | 中程度（LGWAN+DirectConnect） |
| セキュリティレベル係数 | 1.5 | 高（ISMAP対応） |
| GC利用方式係数 | 1.2 | 共同利用（ガバナンス追加） |

### 1.2 計画方針

- **Phase 0-1:** 営業・提案フェーズ（バッファなし）
- **Phase 2-3:** 要件・見積フェーズ（バッファ 10%）
- **Phase 4-6:** 設計・構築・テスト（バッファ 15%、複雑性高）
- **Phase 7-8:** 移行・運用（バッファ 20%、リスク高）
