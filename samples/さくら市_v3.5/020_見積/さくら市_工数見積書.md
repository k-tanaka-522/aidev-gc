## 1. プロジェクト概要サマリー

### 1.1 案件基本情報

| 項目 | 内容 |
|------|------|
| **対象システム** | マイナンバーカード関連サービス（住民向けWebポータル + 庁内業務システム + バッチ・連携処理） |
| **現行構成** | Heroku（Node.js x3 dyno + PostgreSQL + Redis + AWS S3 + Cloudflare CDN） |
| **移行先** | ガバメントクラウド AWS（ap-northeast-1）、共同利用グループ |
| **移行方式** | R1（リホスト + 一部リプラットフォーム: ECS/Fargate, RDS, ElastiCache） |
| **GC利用方式** | 共同利用（関東圏県庁グループ） |
| **セキュリティレベル** | 高（ISMAP対応必須、マイナンバー取扱い） |
| **ネットワーク** | LGWAN接続（住基ネット連携）+ VPN（コンビニ交付）+ インターネット |
| **ASP連携** | 3個（住基ネット、コンビニ交付、マイナポータル） |
| **本稼働予定** | 2027年3月31日 |
| **総期間** | 12ヶ月（2026年4月 - 2027年3月） |
| **予算範囲** | 3,000万円 - 5,000万円 |

## 4. 3点見積（楽観/標準/悲観）

### 4.1 PERT法によるフェーズ別3点見積

| フェーズ | 楽観値(O) | 標準値(M) | 悲観値(P) | 期待値(E) | 標準偏差 | 備考 |
|---------|----------:|----------:|----------:|----------:|---------:|------|
| Phase 0 | 55 | 72 | 100 | 74.5 | 7.5 | GCAS申請の不確実性 |
| Phase 1 | 130 | 160 | 220 | 165.0 | 15.0 | 顧客側ヒアリング協力度に依存 |
| Phase 2 | 155 | 190 | 260 | 196.7 | 17.5 | ISMAP要件の深さに依存 |
| Phase 3 | 170 | 210 | 280 | 216.7 | 18.3 | IaCコード複雑度に依存 |
| Phase 4 | 130 | 160 | 220 | 165.0 | 15.0 | テスト範囲・不具合数に依存 |
| Phase 5 | 85 | 110 | 160 | 114.2 | 12.5 | セキュリティ指摘件数に依存 |
| Phase 6 | 70 | 90 | 130 | 93.3 | 10.0 | リハーサル結果に依存 |
| Phase 7 | 45 | 60 | 90 | 62.5 | 7.5 | 本番データ量・切替時間に依存 |
| Phase 8 | 70 | 90 | 120 | 91.7 | 8.3 | インシデント発生頻度に依存 |
| **合計** | **910** | **1,142** | **1,580** | **1,179.5** | - | |

```
計算式: 期待値(E) = (O + 4M + P) / 6
標準偏差(sigma) = (P - O) / 6

合計の標準偏差 = sqrt(7.5^2 + 15^2 + 17.5^2 + 18.3^2 + 15^2 + 12.5^2 + 10^2 + 7.5^2 + 8.3^2)
              = sqrt(56.3 + 225 + 306.3 + 335 + 225 + 156.3 + 100 + 56.3 + 68.9)
              = sqrt(1,529)
              = 39.1 人日

95%信頼区間: 1,179.5 +/- 1.96 x 39.1 = 1,179.5 +/- 76.6
           = [1,103, 1,256] 人日
```

## 5. クロスチェック（ボトムアップ法 x 類推法）

### 5.1 ボトムアップ法結果

上記フェーズ別詳細積算の合計: **1,142人日**

### 5.2 類推法結果

| 項目 | 参考案件（A市R1移行） | さくら市案件 | 係数 |
|------|-------------------|------------|------|
| 自治体規模 | 中規模（15万人） | 中規模（12万人） | 0.9 |
| 移行方式 | R1 | R1 | 1.0 |
| GC利用方式 | 単独利用 | 共同利用 | 1.2 |
| セキュリティ | 中 | 高（ISMAP） | 1.3 |
| ネットワーク | LGWAN | LGWAN | 1.0 |
| 参考案件実績工数 | 950人日 | - | - |

```
推定工数 = 950 x 0.9 x 1.0 x 1.2 x 1.3 x 1.0
         = 950 x 1.404
         = 1,334 人日
```

ウェイト調整法（影響度加重平均）:
```
- 自治体規模（ウェイト20%）: 0.9 x 0.2 = 0.18
- 移行方式（ウェイト25%）: 1.0 x 0.25 = 0.25
- セキュリティ（ウェイト30%）: 1.3 x 0.30 = 0.39
- GC利用方式（ウェイト15%）: 1.2 x 0.15 = 0.18
- ネットワーク（ウェイト10%）: 1.0 x 0.10 = 0.10

合計係数 = 0.18 + 0.25 + 0.39 + 0.18 + 0.10 = 1.10

推定工数 = 950 x 1.10 = 1,045 人日
```

### 5.3 クロスチェック結果

| 手法 | 見積工数 | ウェイト | 加重値 |
|------|--------:|------:|------:|
| ボトムアップ法 | 1,142 | 45% | 514 |
| 類推法（乗積） | 1,334 | 20% | 267 |
| 類推法（加重平均） | 1,045 | 15% | 157 |
| 3点見積（期待値） | 1,180 | 20% | 236 |
| **採用見積値** | - | - | **1,174** |

```
乖離分析:
- ボトムアップ vs 類推法（乗積）: (1,334 - 1,142) / 1,142 = +16.8%
  → やや高め。乗積法はセキュリティ影響を過大評価の可能性
- ボトムアップ vs 類推法（加重）: (1,045 - 1,142) / 1,142 = -8.5%
  → 許容範囲内
- ボトムアップ vs 3点見積: (1,180 - 1,142) / 1,142 = +3.3%
  → 良好な整合性

判定: ボトムアップ法の 1,142人日 を採用。
類推法（乗積）との乖離は、セキュリティ要件の波及が全フェーズに均等ではないため。
```
