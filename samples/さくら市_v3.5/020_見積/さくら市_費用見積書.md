## 4. RI/Savings Plans活用によるコスト最適化案

### 4.1 本稼働後のコスト最適化

本番稼働後（2027年4月以降）のAWS月額コストを最適化するための提案。

| 最適化施策 | 対象サービス | 削減率 | 最適化後月額 | 備考 |
|----------|------------|------:|----------:|------|
| **Compute Savings Plans（1年）** | ECS/Fargate | -30% | 44,100 | 1年コミット |
| **RDS Reserved Instance（1年）** | RDS PostgreSQL | -35% | 56,550 | 全前払い |
| **ElastiCache Reserved（1年）** | ElastiCache Redis | -30% | 35,700 | 全前払い |
| その他サービス | ALB, NAT, S3等 | 0% | 114,000 | オンデマンド据置 |
| **月額合計（最適化後）** | | | **250,350** | **オンデマンド比 -20.5%** |

```
年間削減額:
  オンデマンド年額: 315,000 x 12 = 3,780,000円
  最適化後年額:     250,350 x 12 = 3,004,200円
  年間削減額:       775,800円（約20.5%削減）

RI/SP 前払い費用:
  Compute SP 1年: Fargate月額63,000 x 12 x 0.7 = 529,200円（一括）
  RDS RI 1年:     RDS月額87,000 x 12 x 0.65 = 678,600円（一括）
  ElastiCache RI: Redis月額51,000 x 12 x 0.7 = 428,400円（一括）
  前払い合計:     1,636,200円

ROI: 投資回収期間 = 1,636,200 / 775,800 = 2.1年
     → 1年コミットで約47%回収、2年目以降は純粋に削減効果
```

### 4.2 さらなる最適化（2年目以降の検討）

## 12. 除外事項・特記

### 12.1 本見積に含まれない費用

| 項目 | 概算費用 | 備考 |
|------|--------:|------|
| 既存Heroku環境の解約・データ消去 | 顧客負担 | 移行完了後に顧客にて実施 |
| LGWAN接続回線費用（DirectConnect） | 県庁負担 | 共同利用グループの回線費用按分 |
| 既存システムの並行運用費用 | 顧客負担 | 移行完了まで（最大6ヶ月） |
| ISMAPクラウドサービス利用料 | AWS含む | AWS GC利用料に包含 |
| ドメイン・SSL証明書費用 | 実費 | ACM（AWS Certificate Manager）で無料 |

### 12.2 為替リスク

- AWS利用料はUSD建てのため、為替変動の影響を受ける
- 本見積は1USD = 150円で計算
- 為替変動が+/-10%を超える場合は、見積の見直しを協議

### 12.3 利用量変動リスク

- 住民向けポータルのアクセス数が想定（500同時接続）を大幅に超える場合、ECS/CloudFrontのコスト増加
- データ量が想定（500GB）を超える場合、S3/RDSのストレージコスト増加
- 上記リスクはAuto Scalingにより性能は確保されるが、コストは従量課金
