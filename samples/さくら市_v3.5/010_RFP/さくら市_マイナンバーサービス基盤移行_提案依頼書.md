## 1. 調達の概要

### 1.1 件名
さくら市マイナンバーサービス基盤のガバメントクラウド移行に係る基本設計・詳細設計・構築・テスト・運用一式

### 1.2 目的
さくら市が現在Heroku上で運用しているマイナンバーカード関連サービスをガバメントクラウド（AWS）へ移行し、ISMAP対応、セキュリティ強化、および長期的な運用コスト最適化を実現する。

### 1.3 対象システム概要
- **住民向けWebポータル**: マイナンバーカード申請状況確認、各種届出手続（電子申請）、証明書自動交付申請
- **庁内業務システム**: 住民情報照会、届出処理、統計分析、監査ログ
- **バッチ・連携**: 住基ネット同期（日次）、コンビニ交付連携、マイナポータル連携

### 1.4 現在地
- 稼働年数: 7年
- 利用者数: 住民約12万人、職員約300人
- 現行環境: Heroku（Node.js + PostgreSQL + Redis + AWS S3 + Cloudflare CDN）

### 1.5 調達範囲
本調達は以下の全工程を対象とする：

1. **基本設計フェーズ** — ガバメントクラウド上のアーキテクチャ設計、セキュリティ設計、移行方針確定
2. **詳細設計フェーズ** — IaCコード設計、ネットワーク・ストレージ・DB詳細設計、運用設計
3. **構築フェーズ** — IaCによるインフラ構築、アプリケーション動作確認環境整備
4. **テストフェーズ** — 結合テスト、性能テスト、セキュリティテスト、ユーザー受入テスト
5. **移行フェーズ** — 移行計画書作成、本番移行、切戻し検証
6. **運用引継フェーズ** — 運用手順書作成、運用チーム教育、初期対応（3ヶ月）

## 3. 移行先環境の要件

### 3.1 クラウド選定
- **必須**: ガバメントクラウド（AWS）を使用すること
- **共同利用**: 関東圏県庁が構築した GC 共同利用グループに参加すること
- **ISMAP**: マイナンバー関連サービスのため、ISMAP認定サービスのみを使用すること

### 3.2 GC共同利用グループの参加形式
- 既存の県共同利用グループの専用 AWS アカウントを利用
- 県のセキュリティ規格（CCIS ガイドライン）に準拠
- 県庁 IAM ユーザーとのクロスアカウントアクセス

### 3.3 ネットワーク環境
- **LGWAN接続**: LGWAN-ASP接続サービスを利用し、庁舎内ネットワークと県庁を経由して住基ネット等へ接続
- **インターネット接続**: NAT Gateway を経由した安全な出口制御
- **管理アクセス**: VPC Endpoint（Systems Manager Session Manager）による踏み台不要な安全な管理

### 3.4 ネットワークセキュリティ
- VPC は単一（または複数AZを含む 1 VPC）で構成し、セキュリティグループとNACL で層別化すること
- WAF（AWS WAF）をアプリケーション前段に配置し、共通攻撃からの保護を実装
- GuardDuty による脅威検知、Security Hub による統合セキュリティ監視

## 4. 機能要件

### 4.1 住民向けWebポータル
- マイナンバーカード申請状況確認（リアルタイム）
- 各種届出手続（転居、世帯変更等）の電子申請
- 証明書自動交付申請、交付結果確認
- 通知機能（メール・SMS）
- モバイル対応（スマートフォン・タブレット）
- アクセシビリティ対応（WCAG 2.1 AA レベル）

### 4.2 庁内業務システム
- 住民情報照会（グループ権限ベースのアクセス制御）
- 届出内容の承認・処理フロー
- 統計分析・レポート生成
- 監査ログ（すべての情報閲覧・変更の記録）
- ユーザー管理（部署別権限設定）

### 4.3 バッチ・連携処理
- 住基ネット同期（毎日深夜）：新規住民取込、転出者削除
- コンビニ交付連携：交付結果同期（リアルタイム）
- マイナポータル連携：行政サービス検索・申請（インターネット経由）
- 月次統計集計：件数別集計、トレンド分析

## 5. 非機能要件

### 5.1 可用性・信頼性
| 項目 | 要件 |
|------|------|
| 可用性（住民向け） | 99.9% 以上（年間ダウンタイム 8.76 時間以内） |
| 可用性（庁内） | 99.5% 以上（年間ダウンタイム 43.8 時間以内） |
| RTO（住民向け） | 4時間 |
| RTO（庁内） | 8時間 |
| RPO（住民向け） | 1時間 |
| RPO（庁内） | 4時間 |

### 5.2 性能
- **同時接続**: 500ユーザー（通常）
- **ピーク接続**: 1,000ユーザー（年度末届出ラッシュ想定）
- **レスポンスタイム**: 画面表示 2秒以内、API 応答 1秒以内（95パーセンタイル）
- **バッチ処理**: 住基ネット同期 2時間以内完了

### 5.3 セキュリティ
- **ISMAP 対応**: 認定サービスのみ使用、認定済みアーキテクチャに基づく設計
- **マイナンバー保護**: 暗号化（転送中: TLS、保存時: AWS KMS）、アクセス制御厳格化
- **監査ログ**: すべての操作を記録、CloudTrail + CloudWatch Logs で 1年間保持
- **脅威検知**: GuardDuty、Security Hub、AWS Config で継続的なコンプライアンス監視
- **ペネトレーションテスト**: 本稼働前に実施予定

### 5.4 データ保護・バックアップ
- **暗号化**: EBS（AES-256）、RDS（AES-256）、S3（AES-256）
- **バックアップ頻度**: データベース日次、ファイルシステム日次
- **保持期間**: 本番データ 30日、アーカイブ 1年
- **リストア検証**: 月次のリストアテスト実施

### 5.5 運用・保守
- **監視**: 24/365 クラウドインフラ監視
- **パッチ適用**: OS、ミドルウェア月次更新、セキュリティパッチは緊急時即対応
- **ログ管理**: CloudWatch Logs + CloudTrail、日本国内リージョンのみ保存
- **SLA**: インシデント初期対応 30分以内、復旧目標値は上記 RTO に準拠
