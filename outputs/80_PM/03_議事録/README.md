# 議事録フォルダ

命名規則: `YYYYMMDD_[会議種別]_議事録.md`

例:
- `20260415_定例会_議事録.md`
- `20260501_設計レビュー_議事録.md`
- `20260601_フェーズゲート_議事録.md`

## 議事録テンプレート

```markdown
# [会議種別] 議事録

**日時:** YYYY-MM-DD HH:MM
**参加者:** 
**議題:**

## 決定事項

| # | 決定内容 | 関連QA# | 関連課題# |
|---|---------|--------|---------|

## アクションアイテム

| # | 内容 | 担当 | 期限 |
|---|------|------|------|

## 次回定例

**日時:** YYYY-MM-DD HH:MM
**議題（予定）:**
```
