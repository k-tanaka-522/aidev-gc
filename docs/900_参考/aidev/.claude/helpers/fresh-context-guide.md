# Fresh Context 実装ガイド

サブエージェント委譲時のコンテキスト管理ガイド。

---

## 概要

**問題**: PM が長い会話を続けると、コンテキスト汚染でサブエージェントの精度が低下する。

**解決策**: タスクごとに新規サブエージェントを起動し、状態は `.claude-state/` に永続化する。

---

## Fresh Context の仕組み

### Claude Code の Task ツール動作

```
PM (親エージェント)
  │
  ├─ Task ツール呼び出し
  │    └─ 新規サブエージェント起動（独立したコンテキストウィンドウ）
  │
  ├─ Task ツール呼び出し
  │    └─ 別の新規サブエージェント起動
  │
  └─ ...
```

**重要な特性**:
- 各サブエージェントは独自のコンテキストウィンドウで動作
- サブエージェント同士は直接通信しない
- サブエージェントは別のサブエージェントを起動できない（ネスト不可）
- 最大7つの並列サブエージェント実行可能

### 状態の永続化

サブエージェント間で情報を共有するには、ファイルシステムを使用する。

```
.claude-state/
  ├─ context.md          # 現在のセッション状況サマリ
  ├─ project-state.json  # プロジェクト基本情報
  ├─ tasks.json          # タスク進捗
  ├─ decisions.json      # 決定事項記録
  └─ reviews/            # レビュー結果
```

## PM の委譲フロー

### 1. 委譲前: 状態を永続化

```markdown
**YOU MUST 委譲前に実行**:
1. `.claude-state/context.md` に現在の状況を記録
2. `.claude-state/decisions.json` に関連する決定事項を記録
3. 必要なファイルパスを整理
```

### 2. 委譲時: Task ツール呼び出し

```markdown
**Task ツール呼び出し例**:
- subagent_type: "coder"
- prompt: |
    ## タスク
    {具体的なタスク内容}

    ## 参照ファイル
    - 実装計画書: docs/05_実装計画/YYYY-MM-DD-feature.md
    - 技術標準: .claude/docs/40_standards/

    ## 前提条件
    - {決定事項を簡潔に}

    ## 成果物
    - {期待する成果物}
```

### 3. 委譲後: 結果を記録

```markdown
**YOU MUST 委譲後に実行**:
1. サブエージェントの結果を確認
2. `.claude-state/tasks.json` を更新
3. 必要に応じて `.claude-state/decisions.json` を更新
4. ユーザーに報告
```

## サブエージェント側のルール

### コンテキスト取得

サブエージェントは委譲時に以下を読む:

```markdown
1. 自身の AGENT.md（役割定義）
2. 関連する SKILL.md（スキル定義）
3. 委譲時に指定されたファイル
4. 必要に応じて `.claude-state/` の状態ファイル
```

### コンテキスト汚染の防止

```markdown
**禁止事項**:
- 過去のセッション情報を推測する
- 指定されていないファイルを勝手に参照する
- 他のサブエージェントの成果物を勝手に変更する

**推奨事項**:
- 不明点は PM に質問（結果として返す）
- 成果物は指定されたパスに出力
- 状態変更は `.claude-state/` に記録
```

## 並列実行ガイド

### 並列実行可能なケース

```markdown
✅ 独立した設計書の作成
  - App-Architect: アプリ設計
  - Infra-Architect: インフラ設計

✅ 独立したレビュー
  - Consultant: ビジネス観点
  - App-Architect: 技術観点
```

### 順次実行が必要なケース

```markdown
❌ 依存関係があるタスク
  - 設計完了 → 実装開始
  - Stage 1 レビュー → Stage 2 レビュー
  - API設計完了 → 画面設計開始
```

### 並列実行の呼び出し例

```markdown
**同時に3つのレビューを実行**:

Task 1:
  subagent_type: "consultant"
  prompt: "要件定義書のビジネス観点レビュー..."

Task 2:
  subagent_type: "app-architect"
  prompt: "要件定義書のアプリ観点レビュー..."

Task 3:
  subagent_type: "infra-architect"
  prompt: "要件定義書のインフラ観点レビュー..."
```

## トラブルシューティング

### サブエージェントが古い情報を参照している

**原因**: `.claude-state/` の更新漏れ
**対策**: 委譲前に必ず状態を更新する

### サブエージェントの成果物が矛盾している

**原因**: 並列実行時の競合
**対策**: 依存関係がある場合は順次実行

### サブエージェントが期待と異なる動作をする

**原因**: プロンプトの情報不足
**対策**:
- 参照ファイルを明示
- 成果物の期待を具体的に記載
- 制約条件を明記

- [ ] 結果を確認した
- [ ] `tasks.json` を更新した
