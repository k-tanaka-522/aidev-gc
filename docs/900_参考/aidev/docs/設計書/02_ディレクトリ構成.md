# ディレクトリ構成

## 1. 概要

### 1.1 目的

aidevのファイル配置と各ファイルの役割を定義する。
「誰が」「何を」「どこで」参照・更新するかを明確にする。

### 1.2 設計方針

```
1. 役割ごとにディレクトリを分離
2. 参照者を明確にする
3. 新規追加と既存維持を区別する
```

---

## 2. 全体構成

```
aidev/
├── CLAUDE.md                    # エントリーポイント（PM定義）
│
├── .claude/                     # aidev設定ディレクトリ
│   ├── agents/                  # サブエージェント定義
│   ├── commands/                # ユーザーコマンド
│   ├── skills/                  # スキル（専門知識）
│   ├── docs/                    # ドキュメント
│   └── helpers/                 # 補助ツール
│
├── .claude-state/               # 状態管理（Git管理外）
│   ├── project-state.json
│   ├── tasks.json
│   ├── decisions.json
│   └── context.md
│
├── docs/                        # プロダクト成果物
├── src/                         # ソースコード
├── tests/                       # テストコード
└── infra/                       # インフラコード
```

## 5. Git管理方針

### 5.1 Git管理対象

```
aidev/
├── CLAUDE.md               ✅ Git管理
├── .claude/                ✅ Git管理
├── docs/                   ✅ Git管理
├── src/                    ✅ Git管理
├── tests/                  ✅ Git管理
├── infra/                  ✅ Git管理
└── .claude-state/          ❌ Git管理外
```

### 5.2 .gitignore 設定

```gitignore
# aidev状態ファイル（セッション固有）
.claude-state/

# ただし、スキーマ定義は管理
!.claude-state/_schema/
```

### 5.3 理由

- **Git管理**: チーム共有、バージョン管理が必要なもの
- **Git管理外**: セッション固有の状態、個人の作業状況

## 6. 命名規則

### 6.1 ファイル名

| 種別 | 規則 | 例 |
|------|------|-----|
| エージェント定義 | `AGENT.md` | `coder/AGENT.md` |
| スキル定義 | `SKILL.md` | `typescript/SKILL.md` |
| コマンド定義 | `{command}.md` | `init.md` |
| 状態ファイル | `{name}.json` | `tasks.json` |
| 引継ぎファイル | `context.md` | `context.md` |

### 6.2 ディレクトリ名

| 種別 | 規則 | 例 |
|------|------|-----|
| エージェント | ケバブケース | `app-architect/` |
| スキルカテゴリ | 複数形 | `languages/` |
| スキル | ケバブケース | `c4-modeling/` |
