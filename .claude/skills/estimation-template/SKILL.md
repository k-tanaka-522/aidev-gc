有効期限: 20XX年Y月（+30日）

## 1. 案件概要
- 対象システム: [システム名、機能概要]
- 現行構成: [現状（オンプレ/クラウド/混在）]
- 移行方式: [リフト / R1 / R2 / 新規構築]
- GC利用方式: [単独利用 / 共同利用]
- セキュリティレベル: [低 / 中 / 高 / 最高]
- 予定スケジュール: [開始予定時期→完了予定時期（XX ヶ月）]

## 2. 見積対象範囲
### 対象フェーズ
- ✓ Phase 0: 案件入口
- ✓ Phase 1: 提案見積
- ✓ Phase 2: 要件定義
- ✓ Phase 3: 詳細見積計画
- □ Phase 4-8: 詳細設計～運用（別途見積）

### スコープ
- RFP分析・要件ヒアリング

- 技術提案書作成

### スコープ外
- 本番環境構築（Phase 5以降）
- AWS利用料（見積別途）
- 外部セキュリティ診断（別途契約）

## 4. 内訳（フェーズ別）

### Phase 0: 案件入口 （60人日）
- 体制構築・ガバナンス: 15人日
- GCAS申請準備: 40人日（GC利用の場合）
- 初期要件ヒアリング: 5人日

### Phase 1: 提案見積 （80人日）
- RFP分析・要件抽出: 30人日
- 参考案件調査: 15人日
- 概算見積作成: 30人日
- 営業提案書作成: 5人日

### Phase 2: 要件定義 （180人日）
- ユーザーヒアリング・WS: 60人日
- 現行システム調査: 40人日
- 非機能要件詳細化: 50人日
- 要件定義書作成: 30人日

### Phase 3: 詳細見積計画 （80人日）
- 詳細WBS作成: 25人日
- 工数見積（ボトムアップ+類推法）: 40人日
- スケジュール・リソース計画: 15人日

## 5. 3点見積（楽観/標準/悲観）

| フェーズ | 楽観値 | 標準値 | 悲観値 | 期待値 |
|---------|-------|-------|-------|-------|
| Phase 0 | 45 | 60 | 80 | 62.5 |
| Phase 1 | 60 | 80 | 110 | 83.3 |
| Phase 2 | 140 | 180 | 250 | 186.7 |
| Phase 3 | 60 | 80 | 110 | 83.3 |
| **合計** | **305** | **400** | **550** | **415.8** |

**95% 信頼区間: 415.8 ± 30人日 = [385.8, 445.8]**

## 6. リスク・前提条件

### 前提条件
1. ユーザー側のPM配置、ヒアリング協力体制
2. 既存システムドキュメント（ネットワーク図、システム概要）の提供
3. GCAS申請は提案企業が主体（GC登録企業）
4. セキュリティポリシー・要件は事前に確認

### リスク・対応
| リスク | 影響 | 対策 |
|--------|------|------|
| ユーザー側リソース確保遅延 | Phase 2 遅延 +2週間 | 事前のコミット確保 |
| 既存ドキュメント不足 | 現行調査追加 +30人日 | Phase 1 で詳細ヒアリング |
| 要件の頻繁な変更 | 変更管理タスク +30人日 | 要件凍結会議（Phase 2 末） |

### 除外事項
- 本番環境構築（Phase 4以降）
- AWS利用料の見積（別途 AWS パートナー見積）
- 外部セキュリティ診断（ISMAP対応の場合は別途見積、費用 +800万円程度）
- ユーザー教育・トレーニング（別途 XX 万円）

## 7. 納期

- 見積対象期間: 12営業週間（約3ヶ月）
- 想定開始日: 20XX年Y月
- 想定完了日: 20XX年Y月
- 予備期間（バッファ 20%）: +2週間
- **実効納期: 20XX年Y月 **

## 8. 支払条件（案）
- 契約時: 見積総額の 50%
- Phase 2 完了時: 25%
- Phase 3 完了時: 25%
- 支払期限: 請求月の末日から30日以内

## 9. 有効期限・変更
- 本見積の有効期限: 20XX年Y月（+30日）
- 有効期限後の見積は別途実施
- 要件変更・スコープ拡大の場合は、別途見積・契約を実施
